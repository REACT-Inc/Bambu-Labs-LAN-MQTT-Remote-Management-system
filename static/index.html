Other alerts

Send the same alerts as Discord to Home Assistant, ntfy (phone push), any webhook, or a Discord channel webhook. These work even without the Discord bot. Choose all alerts, or only important ones (errors, failed prints, AI failure alerts).

Which URL to use

ntfy: https://ntfy.sh/your-topic (or your own server), then subscribe to that topic in the ntfy app. Home Assistant webhook: http://homeassistant.local:8123/api/webhook/<id> from an automation's Webhook trigger (no token). Home Assistant notify: http://homeassistant.local:8123/api/services/notify/mobile_app_your_phone with a long-lived access token. Webhook: any URL that accepts JSON {printer, title, message, level}. Discord webhook: a channel's webhook URL.

Quick guide

Queue a print: upload a sliced Bambu Studio or OrcaSlicer .3mf, or enter a file path already on the printer. STL and unsliced projects cannot print directly.

Before starting: clear the plate and check the printer profile, material, selected plate, and AMS mapping.

Needs review: inspect the physical printer, then record the outcome. An unconfirmed start is never automatically retried.

Reprint: adds a completed managed job back to the queue. It does not immediately start the printer.

Camera: snapshots depend on your model, firmware, and enabled LAN access.

    Swapmod A1m (Swap Systems)

    Use Swaplist to generate the full batch file for this kit, then upload it as one queue job. The file handles plate changes within that batch. This app does not generate or add swap G-code. Check the starting setup before each separate batch.

    Calibrate camera to bed

    Click the corners of the bed's printable area on the picture, in this order: 1 front-left, 2 front-right, 3 back-right, 4 back-left. Front is the side nearest the door; front-left is where the printer's X and Y are 0. With this, the AI can tell plastic where the print file puts it from material where nothing should be printed.
